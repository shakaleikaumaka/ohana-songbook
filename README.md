## 🎼 How to add a song

1. Write the song as a markdown file in `/shared/kb/songbook/`
2. Follow the format: title, subtitle, dedication, suggested feel, verses with section labels, detail map (every line = a real event), cast, metadata
3. Add the entry to this index
4. Every line must be TRUE — receipts only, no fiction

## 📐 The Laws of the Songbook

- **Every line = a real event.** If it didn't happen, it doesn't get a verse.
- **Mahalo energy.** Even the disasters are celebrations of learning.
- **CC0 to the universe.** Every song is a gift.
- **Heart first, wallet second, always.** 🌺
